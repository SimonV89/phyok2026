## 快速索引

- **敏感信息保护**：严禁任何凭据硬编码，`env2` 严格排除 Git
- **UI 文案规范**：禁止"开发文案"，面向真实用户，专业自然，中文完整
- **RAG 召回阈值**：`minScore` 设为 0.16，确保弱语义关联命中
- **计费幂等**：通过 `runId` 实现扣减幂等，防止重复计费
- **支付签名**：签名字符串必须严格处理 `sign_type`
- **首屏优化**：`MemoryStarMapPanel`、`EmailLoginCard`、Markdown 渲染器按需懒加载
- **H5 Drawer**：必须从右侧滑出，`translateX`，宽度 `min(86vw, 368px)`

## 使用约定

1. **首次接触本项目**：先读 `工程约束/README.md`，再读本总索引
2. **处理特定领域**：加载对应子目录的 `README.md`
3. **处理具体模块**：加载对应 `*.md` 文件
4. **遇到未知错误**：先查 `经验积累/常见问题与修复.md`
